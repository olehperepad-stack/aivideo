# Повторная проверка FramePilot 0.15.2

Дата: 11 ноября 2026. Проверены исходники, обработка кадров, переключение источников, сохранение проектов и сеансов, очередь экспорта, фоновые потоки, интеграция OBS, сборка и упаковка. Среда: Apple M5, 16 ГБ, macOS 27.2.1, arm64. [Предыдущая проверка 0.15.1](./AUDIT.md).

## Найденные и исправленные ошибки

| Условие | Ошибка | Исправление |
| --- | --- | --- |
| Рядом с проектом существует файл с именем `имя-проекта.json.tmp` | Файл перезаписывался и удалялся при сохранении. Если он был исходным видео, терялся исходник. | Уникальный временный файл, синхронизация записи и атомарная замена проекта. Существующий файл `.tmp` сохраняется. |
| Результат одного задания очереди совпадает с исходником другого | Очередь могла перезаписать исходник до выполнения следующего задания. | Проверка конфликтов в обе стороны при добавлении; конфликтующее задание отклоняется. |
| Старая камера присылает ошибку после остановки или смены устройства | Сообщение могло пометить новую камеру неисправной и остановить её. | Обработчик принимает ошибки только текущего поколения захвата. |
| После смены камеры приходит кадр предыдущего устройства | Общий видеоприёмник пропускал его как кадр новой камеры. | Для каждого открытия создаётся отдельный видеоприёмник; запоздалые кадры отбрасываются. |
| Ответ на старый запрос разрешения приходит после смены камеры | Отказ мог заменить статус работающей камеры. | Проверяется актуальность запроса до обработки любого ответа на разрешение. |
| При смене видео на фото, камеру или экран приходит старое событие конца видео | Автоповтор мог сбросить выделение в новом источнике. | События плеера учитываются только для активного файлового источника. |
| Плеер на паузе либо его текущий статус уже изменился | Старое событие конца ролика могло запустить воспроизведение. | Автоповтор сверяется с текущим статусом и паузой. Нормальный повтор завершившегося ролика сохранён. |
| Ошибка старого видео приходит при работе с другим источником | Сообщение заменяло статус фото, камеры или экрана. | Ошибки неактивного плеера игнорируются. |
| Фото имеет очень большое соотношение сторон | При уменьшении принудительные 8 пикселей по короткой стороне растягивали панораму. | Размер рассчитывается с сохранением соотношения сторон и минимумом 1 пиксель. |
| Короткая сторона кадра при уменьшении округляется до нуля | OpenCV выдавал ошибку вместо обработки изображения. | Размер ограничен минимумом 1 пиксель на входе, в анализе, обработке, трекере и захвате Qt. |

Проверка нового способа атомарной записи выявила рост размера JSON при форматировании. Сохранён компактный формат проектов. Добавлен тест сохранения 200 000 отсчётов с координатами полной точности в пределах лимита чтения 64 МБ. Воспроизведение: `test-results/reliability-0152-large-project-reproduced.log`.

Также исправлено ожидание в существующем UI-тесте: он проверяет отсутствие ожидающего перерендеринга, прежде чем оценивать новый размер и статус кадра.

## Пределы проверки

Настоящая установка и запуск Windows EXE, Windows-захват, реестр и UAC требуют проверки на Windows. В архиве находятся исходники и команды сборки, не готовый EXE. Успешные тесты общего движка на Mac не подтверждают работу системных API Windows.

Физическая камера, реальный поток захвата экрана с разрешениями macOS, Genymotion, BlueStacks, онлайн-эмуляторы и принимающие Android-приложения в этом прогоне не проверялись. Камера OBS проверена реальным локальным получателем Qt.

Универсальное распознавание любого предмета и любого интерфейса не заявляется. Оценка качества на пользовательских роликах требует самих роликов и ожидаемого результата. Успешные тесты не гарантируют отсутствие всех ошибок.

Подробные журналы доступны в рабочей папке проекта. Windows-архив включает этот отчёт без журналов macOS.

## Повторный запуск проверок

```sh
.venv/bin/pytest -q
.venv/bin/ruff check src tests tools
.venv/bin/ruff format --check src tests tools
.venv/bin/python -m pip check
dist/FramePilot.app/Contents/MacOS/FramePilot --self-test --report test-results/recheck-mac.json
FRAMEPILOT_VISION_BACKEND=yunet dist/FramePilot.app/Contents/MacOS/FramePilot --portable-self-test --report test-results/recheck-common.json
```

Для проверки реального OBS используется `tools/check_obs.py`; перед запуском нужно закрыть обычный OBS. Контроллер запускает отдельный экземпляр и восстанавливает его настройки после теста. Пароли не записываются в отчёты.
